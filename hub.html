⚠ Shared login isn't set up yet. Daily Updates, Social Media, Contacts, Announcements and Quick Links need a free Firebase project so everyone can sign in and sync live. Takes about 5 minutes, one time:
  1. Go to console.firebase.google.com → Add project (free, no card needed) → any name, e.g. pls-hq
  2. Build → Firestore Database → Create database → pick any region → start in production mode
  3. Build → Authentication → Get started → enable the Email/Password provider
  4. Still in Authentication, click Users → Add user and create one login per team member (their email + a password you choose) — e.g. riccardo@packlifestore.com
  5. In Firestore → Rules, replace the rules with:
    rules_version = '2'; service cloud.firestore { match /databases/{db}/documents { match /pls_ops/{doc} { allow read, write: if request.auth != null; } } } then click Publish
  6. Click the ⚙ gear → Project settings, scroll to "Your apps", click </> (Web), register an app (any nickname) — you'll get a config object with apiKey, authDomain, projectId, storageBucket, messagingSenderId, appId
  7. Paste all six values into the FIREBASE_CONFIG block near the top of the <script> in this file, daily-updates.html, social-media.html and contacts.html — same values in all four
  8. Open firebase_sync_core.js's TEAM_EMAIL_MAP and match each email to the display name you want shown (defaults to Riccardo / Anna / Chris)
Until then, everything you add here only shows up on your own screen, and no login is required.
